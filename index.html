RGB转YUV

发表于 2026-08-05 分类于 图像处理

首先说一说YUV颜色模型，单单就YUV颜色模型来说，就有很多中叫法，而且总是让人颇感困惑。一般来讲，我们把YUV、Y`UV、YCbCr, YPbPr包含在YUV颜色模型的范围内，其中Y都表示亮度，UV表示两个色度分量，但是具体的颜色模型的用途又各不相同，当然，他们与RGB的互转公式也就不尽相同。那就先说说这些不同叫法的YUV的用途和由来。在电视系统发展的早期，YUV和Y`UV都是颜色信息的模拟信号编码形式，虽然Y和Y`都表示亮度，但是两种亮度的意义却天差地别，Y用来代指luminance,表示的是自然颜色的亮度，而Y`代指luma，表示的是经过伽马压缩之后电信号的强度。在现在的计算机系统中，YUV一般用来代指YCbCr,用来表示文件的编码格式，用于数字视频的编码，而YPbPr颜色模型常常用在模拟分量视频中。所以YUV颜色模型到RGB颜色模型的转换，应该对应两种方式，分别是模拟YUV->模拟RGB、数字YUV->数字RGB。不过因为标清、高清、以及超清幅面，YUV转RGB的权重值各不相同，需要将模拟信号和数字信号再做一次幅面划分，就出现了2*3 = 6，6中转换公式。

ISP初探

发表于 2026-08-05 分类于 ISP

简介

凡是在图像领域工作的人，都会经常听到ISP (Image Signal Process, 图像信号处理)，知道ISP对图像质量非常重要。比如华为和小米竞争手机拍照和录像效果，主要的竞争领域就是ISP；做AI (Artificial Intelligence, 人工智能) 的人也知道，如果ISP不给力，后续的AI处理效果会受到影响。

ISP模块参数调整

在ISP图像调试中，调整的依据主要包括以下几个方面：

图像质量要求：

不同的应用场景对图像质量的要求不同，例如在低光环境下拍摄时，需要优先考虑降噪和亮度调整，以确保图像清晰可见。

处理流程：

通常的处理流程是先进行亮度调整；
然后进行降噪和锐化；
最后进行颜色调整。
这是因为亮度调整可以为后续处理提供基础，而降噪可以消除影响锐化和颜色调整的噪声，从而提高最终图像的质量。

人眼感知：

人眼对亮度和对比度的敏感度较高，因此在图像处理时，首先调整亮度可以更好地满足人眼的视觉需求。

技术标准：

在图像处理领域，通常会参考行业标准和技术文献，以确保处理流程的科学性和有效性。例如，使用标准色卡进行颜色校正，确保颜色的准确性和一致性。

各项异性检测图像map图

发表于 2026-07-29 更新于 2026-08-05 分类于 图像处理

“各向异性（Anisotropy）”往往比单纯用梯度幅值更精准、更抗噪！

理由如下：

  1. 梯度幅值（Gradient Magnitude）容易被噪声误判： 噪声在图像平坦区会导致梯度突然变大，产生假边缘，导致 ϕ(G) 误判，去噪不彻底。

    2. 各向异性描述的是“结构一致性”：

    * 平坦区 / 纯噪声区：各个方向的变化率差不多，表现为各向同性（Isotropic，各向异性指标趋近于 0）。

    * 真实边缘 / 纹理区：沿着边缘方向灰度变化极小，垂直于边缘方向灰度变化极大，表现为高各向异性（Anisotropic，各向异性指标趋近于 1）。

因此，利用各向异性度量（Anisotropy Measure）作为 Map 图，可以完美抵御平坦区的噪声干扰，只在真正的线条/边缘处保留 NLM 的结构识别能力。

一、 如何计算各向异性 Map？（基于结构张量）

计算局部各向异性最经典、稳健的方法是利用结构张量（Structure Tensor / Second Moment Matrix）：

  1. 计算图像梯度：Jx​=∂x∂I​,Jy​=∂y∂I​
  2. 构建结构张量矩阵（对梯度外积进行高斯高斯滤波平滑以抵御噪声）：
    $S = \begin{bmatrix} J_{xx} & J_{xy} \ J_{xy} & J_{yy} \end{bmatrix}$
  3. 求解特征值 λ1​,λ2​ (λ1​≥λ2​≥0)：
    * λ1​ 代表最大变化率方向的能量；


* λ2​ 代表最小变化率方向的能量。

  1. 计算各向异性指标 A： 常用的各向异性度量函数有：

    $A = \frac{\lambda_1 - \lambda_2}{\lambda_1 + \lambda_2 + \epsilon}$​

    > 物理意义：

    > * 平坦区或噪声区：λ1​≈λ2​→A≈0 （各向同性，Patch diff 缩放归零，退化为均值/高斯，去噪极强）。

    > * 单向强边缘/纹理：λ1​≫λ2​→A≈1 （高各向异性，Patch diff 保持不变，开启 NLM 边缘保护）。

二、 将各向异性 Map 代入 NLM 的 Patch 差异

用各向异性指标 A(x,y)∈[0,1] 替换原来的 ϕ(G)，直接调控 Patch 的原始差异：

$D_{adj}(i,j) = A(i) \cdot D_{raw}(i,j)$

  • 当 A(i)→0（平坦区/噪声）：Dadj​→0，所有 Patch 权重 exp(0)=1，退化为均值滤波。

    * 当 A(i)→1（真实边缘）：Dadj​→Draw​，恢复标准 NLM 灰度匹配。
