发表于 2026-09-21 分类于 图像处理

首先说一说YUV颜色模型，单单就YUV颜色模型来说，就有很多中叫法，而且总是让人颇感困惑。一般来讲，我们把YUV、Y`UV、YCbCr, YPbPr包含在YUV颜色模型的范围内，其中Y都表示亮度，UV表示两个色度分量，但是具体的颜色模型的用途又各不相同，当然，他们与RGB的互转公式也就不尽相同。那就先说说这些不同叫法的YUV的用途和由来。在电视系统发展的早期，YUV和Y`UV都是颜色信息的模拟信号编码形式，虽然Y和Y`都表示亮度，但是两种亮度的意义却天差地别，Y用来代指luminance,表示的是自然颜色的亮度，而Y`代指luma，表示的是经过伽马压缩之后电信号的强度。在现在的计算机系统中，YUV一般用来代指YCbCr,用来表示文件的编码格式，用于数字视频的编码，而YPbPr颜色模型常常用在模拟分量视频中。所以YUV颜色模型到RGB颜色模型的转换，应该对应两种方式，分别是模拟YUV->模拟RGB、数字YUV->数字RGB。不过因为标清、高清、以及超清幅面，YUV转RGB的权重值各不相同，需要将模拟信号和数字信号再做一次幅面划分，就出现了2*3 = 6，6中转换公式。

ISP初探

发表于 2026-09-21 分类于 ISP

简介

凡是在图像领域工作的人，都会经常听到ISP (Image Signal Process, 图像信号处理)，知道ISP对图像质量非常重要。比如华为和小米竞争手机拍照和录像效果，主要的竞争领域就是ISP；做AI (Artificial Intelligence, 人工智能) 的人也知道，如果ISP不给力，后续的AI处理效果会受到影响。

ISP模块参数调整

在ISP图像调试中，调整的依据主要包括以下几个方面：

图像质量要求：

不同的应用场景对图像质量的要求不同，例如在低光环境下拍摄时，需要优先考虑降噪和亮度调整，以确保图像清晰可见。

处理流程：

通常的处理流程是先进行亮度调整；
然后进行降噪和锐化；
最后进行颜色调整。
这是因为亮度调整可以为后续处理提供基础，而降噪可以消除影响锐化和颜色调整的噪声，从而提高最终图像的质量。

人眼感知：

人眼对亮度和对比度的敏感度较高，因此在图像处理时，首先调整亮度可以更好地满足人眼的视觉需求。

技术标准：

在图像处理领域，通常会参考行业标准和技术文献，以确保处理流程的科学性和有效性。例如，使用标准色卡进行颜色校正，确保颜色的准确性和一致性。

手机作为轻量服务器

发表于 2026-09-21 分类于 Tools

先备份

一、 最完美的实现方案：NANDROID 备份（镜像级）

这是唯一能做到“一键恢复到完全一模一样”的方法。

1. 工作原理

在给手机刷入真正的 Linux 系统之前，先刷入一个第三方 Recovery（如 TWRP 或 OrangeFox）。 在 TWRP 界面中，有一个 Backup（备份） 功能，它可以把手机内部的整个存储结构打包成镜像，包括：

  • System / Super（系统分区）

    * Boot / Vendor（内核与底层驱动分区）

    * Data（你的所有应用、应用数据、系统设置、桌面布局等）

    * EFS / Persist（基带、Wi-Fi/蓝牙 MAC 地址、IMEI 码等核心参数）

2. 操作流程

  1. 备份：

    * 手机进入 TWRP 界面 -> 点击 Backup -> 勾选所有分区（尤其是 System, Data, Boot, EFS）。

    * 将备份生成的文件拷贝到电脑或 U 盘中妥善保存（手机刷 Linux 时本地存储会被清空）。

    2. 体验 Linux：

    * 抹除 Android 分区，刷入 PostmarketOS 或 Ubuntu Touch 等 Linux 系统。

    3. 一键恢复：

    * 当你不想用 Linux 时，再次进入 TWRP 界面。

    * 把电脑上的备份文件夹放回手机或插上 OTG U 盘。

    * 点击 Restore（恢复），选择之前保存的备份，刷入恢复。

    * 重启后，手机会瞬间变回你备份那一刻的模样，连微信记录、墙纸和打开的标签页都原封不动。

二、 镜像备份的关键限制与“坑点”

虽然 NANDROID 备份很强大，但有以下几点必须注意：

  1. 硬件安全密钥与指纹/锁屏密码（重中之重）

    * 坑点：现代 Android 系统（Android 10 及以上）采用了极严格的硬件加密（FBE - File-Based Encryption）。如果在备份前没有取消锁屏密码/指纹/人脸识别，直接进行备份，后续恢复系统时可能会遇到：

    * 无法进入系统（卡在开机界面）。

    * 提示“密码错误”，或者提示“数据无法解密”。

    * 解法：在进入 TWRP 进行备份之前，必须先在 Android 设置里移除所有锁屏密码、指纹和人脸识别，并将 Google/手机厂商账号（如小米账号、华为账号）退出，然后再重启进 TWRP 进行备份。

    2. 存储空间要求大

    * 包含用户数据的打包文件通常很大（10GB ~ 50GB 不等，取决于你的应用数量）。

    * 必须确保有 OTG U 盘或电脑磁盘空间来接收备份文件。

    3. 专机专用

    * NANDROID 备份是基于特定手机型号甚至固件版本的镜像，绝对不能恢复到另一台不同型号的手机上，否则会导致永久变砖。

安装系统

安装完整 Linux 系统

如果需要运行 Docker 或复杂的 Linux 服务，可以通过工具将手机彻底改造成纯粹的 Linux 设备。

  • 轻度方案（Linux Deploy / proot-distro）：在 Android 系统内部以容器/Proot 形式运行 Linux 系统（无需刷机）。在 Termux 中运行 proot-distro install ubuntu 即可一键获得 Ubuntu 环境。

    * 深度方案（刷入 PostmarketOS / Ubuntu Touch）：直接抹除 Android 系统，刷入专为手机设计的纯 Linux 内核系统（需要手机解锁 Bootloader 且有适配固件）。

通信

手机连接家里的 Wi-Fi 后，获得的只是局域网 IP（例如 192.168.1.X），外网是无法直接访问的。要成为真正的“云服务器”，需要解决外网连通问题：

  1. 内网穿透工具（最简单，无需公网 IP）

    * 免费/现成方案：使用 cpolar、花生壳 或 Ngrok，在 Termux 中运行客户端，直接将本地端口映射为一个公网 URL。

    * 自建方案（推荐）：如果你拥有另一台带公网 IP 的云服务器（如阿里云/腾讯云），可以使用 FRP 或 Rathole 进行点对点穿透。

    2. 虚拟局域网（组网方案）

    * 使用 Tailscale 或 ZeroTier。手机和你的电脑/随身设备都安装客户端后，无论身在何处，都可以像在同一局域网内一样通过固定 IP 访问手机服务器（适合个人私有服务）。

    3. 路由器 DDNS + 端口映射

    * 如果你家里的宽带带有公网 IPv4 或 IPv6 地址，可以在路由器端配置 DDNS（动态域名解析）并开启端口映射（Port Forwarding），直接通过域名访问手机。

## 旧手机改造服务器的“优势”与“坑点”

优势：

  • 自带 USP（不间断电源）：手机电池就是天然的 UPS，断电后依然能维持运行数小时。

    * 低功耗：相比 PC，手机芯片（ARM 架构）待机功耗极低，24 小时开机电费基本可以忽略。

    * 硬件集成度高：自带 Wi-Fi 模块、蓝牙、甚至蜂窝网络（可作为双网络备用）。

需要注意的“坑点”及优化措施：

  1. 电池膨胀/安全隐患（最关键）

    * 风险：长期插电源线 24 小时运行，电池极易膨胀鼓包甚至起火。

    * 解法：

    * 尽量配合智能插座设置定时断电（如电量 80% 停止，20% 恢复）。

    * 有条件或有动手能力的，可以拆除电池，改为直供电模块（假电池直接接 5V/4.2V 电源）。

    * 在系统内开启“电池保护模式”（限制充电上限至 60%-80%）。

    2. Android 系统的后台杀进程机制

    * Android 系统为了省电，会自动关闭后台运行的 Termux 或服务。

    * 解法：必须在手机设置中将 Termux 等应用设为允许后台运行、关闭电池优化，并在 Termux 内开启 termux-wake-lock（防止 CPU 休眠）。

    3. 散热问题

    * 手机没有主动散热风扇，如果高负载运行（如编译代码、视频转码），会导致降频甚至关机。

    * 解法：放置在通风处，或加装一个几块钱的 USB 小散热风扇/贴贴散热片。

绝对色温和相关色温什么意思？怎么计算色温？

色温是表示光源光色的尺度，是光源除显色性以外另一个重要的颜色指标。光源色温可以分为绝对色温和相关色温​，其中绝对色温一般用 T 表示，相关色温一般用 Tc 来表示，它们的单位都是开尔文（K）。那么，绝对色温和相关色温什么意思？怎么计算色温？下文为大家作了介绍。

绝对色温和相关色温什么意思？

色温是光源的重要颜色指标，色温分为绝对色温与相关色温。

当光源发出的光谱与加热一个黑体使其产生同样光谱时，加热黑体所需要的温度就是该光源的绝对色温​。绝对色温的概念是在 1911 年由 Hyde 提出的，一般用 T 表示，单位为开尔文（K），是表示光源特性最基本的参数之一。这里的黑体是指对外来辐射或光线完全吸收的一种理想物体，是不存在的。

绝对色温虽然可以准确地描述光源的颜色，然而对于大部分光源来说，光源的色品坐标不可能与某一绝对温度下的黑体辐射色品坐标完全相同。为此，Raymond Davis 等人提出了相关色温的概念，一般用 Tc 来表示，单位为开尔文（K），它表示与光源具有最相似颜色刺激的黑体辐射的温度。

绝对色温和相关色温计算方法

  1. 绝对色温计算方法

绝对色温在 CIE-1931 色品图上是一条连续的弧形轨迹，这条轨迹称为黑体轨迹线​。光源的色品坐标如果落于黑体轨迹上，则对应的黑体温度就为此光源的绝对色温。

自动曝光技术

发表于 2026-09-03 更新于 2026-09-21 分类于 ISP

自动曝光可以分为亮度获取、亮度分析、曝光调节三个步骤。从实现方式上，自动曝光又可以分为光学方式与电子学方式。一般具有测光功能的摄像机都有至少三种基本的测光方式：中央重点平均测光、中央部分测光和点测光。事实上，无论哪种测光方式都很难兼顾整个画面的亮度。当光照条件是背光（逆光）或是强正面光时，由于场景中最亮和最暗区域具有强烈的对比度，如果仍然采用 上述的常用测光方法，虽然整体的图像亮度仍然是“中间灰度”，但是图像中重要的主体区域就肯定遭遇曝光不足或者曝光过度，所以必须采用更先进的自动曝光控制方法。

一、概述

自动曝光可以分为亮度获取、亮度分析、曝光调节三个步骤。从实现方式上，自动曝光又可以分为光学方式与电子学方式。

（1）光学方式的自动曝光

光学方式的自动曝光需要使用单独的光照传感器来测量光照度，从而进行场景亮度获取。获取亮度后，再结合图像信息与当前光圈值、曝光时间和感光度值ISO信息进行分析，判断当前曝光参数是否合适。如果不合适则进行曝光调节，也就是调节光圈、曝光时间和感光度ISO这三个曝光相关参数。传统的胶片摄像机以及部分数码摄像机采用的就是这种方式。

（2）电子学方式的自动曝光

电子学方式会直接从图像传感器输出的图像信号中获取亮度信息，还能够额外提供对场景的分析能力。相比于光学方式，它节省了测光设备，目前已经被绝大多数数码摄像机采用。由于电子学方式是直接通过摄像机镜头测光，因此这种方式也被称为 TTL (through the lens）方式。我们将会重点讨论这种方式。

对于彩色图像，图像传感器获得的信号属于 RGB 色彩空间。通过下式的色彩空间转换，可以得到 YUV 色彩空间：

Y = 0.299R + 0.578G + 0.114B
U = -0.147R - 0.289G + 0.436B
V = 0.615R - 0.515G - 0.100B

亮度分量Y包含了 93%的图像能量。在获取了每个像素的亮度后，需要对图像的整体亮度情况进行分析，判断其是否过曝或欠曝。

如何判断其是否过曝或欠曝呢？我们需要设置一个理想的视觉亮度作为目标。那么，究竟什么样的亮度才是理想的视觉亮度呢？可假设被摄物体具有18%的固定反光率，这是因为人眼产生的视觉效果中，18%刚好是中间灰度。对于8位的摄像机系统，具有255个灰度级，那么128 就是它的中间灰度。数码摄像机在执行自动曝光时需要使曝光后的图像具有接近中间灰度的整体亮度水平，这也就是理想视觉亮度了。

但需要指出的是，虽然18%的固定反光率或者中间灰度的假设在大多数情况下是可行的，但是不可避免也有失效的时候，这时就需要采用曝光补偿技术了。将得到的图像亮度和目标亮度进行比较后，就可以根据分析结果进行曝光调节了。

曝光调节需要遵循一定的优先原则，包括光圈优先、快门优先等，详细内容可以参考如下链接

摄像机厂商一般会提供若干模式，供用户自行选择。如果已知需要的曝光量，那么根据用户选择的调节策略进行调节己经是一件非常成熟的技术了。现在问题的重点集中在：

  • 如何对环境亮度（即当前图像的亮度）进行分析，从而确定正确的曝光量？

  • 如何判断当前曝光值是否过曝或欠曝？

  • 是针对整个图像，还是图像中的某一块区域？

除了常用的测光技术之外，会重点讨论一些考虑了背光及正面强光等特殊场景的嚗光控制算法。这些算法较之常用测光技术研究性更强，而常用测光技术基本已经应用于商业摄像机中。

二、常用测光技术

一般具有测光功能的摄像机都有至少三种基本的测光方式：中央重点平均测光、中央部分测光和点测光。

1）中央平均测光

中央平均测光也叫中央重点平均测光。中央平均测光主要是考虑到一般摄影者习惯将需要准确曝光的拍摄主体放在取景器的中间，所以这部分拍摄内容往往是最重要的。在进行亮度分析时将中央部分亮度的权重分配较大的比例（约70%）、周围部分则分配较小的比例（约 30%）进行平均亮度计算：

中央部分测光又称为局部测光，测量取景框中央长方形或圆形（椭圆形）范围内的平均亮度为：

（3）点测光

点测光的测光方式与中央部分测光类似，但是测光范围C（i）更小，选取画面的1%~3%的范围求取平均亮度。测光范围的选取也不完全局限于中央部分。点测光基本不受测光区域外其他景物亮度的影响，能够做到对表现主体的准确曝光。

三种测光模式各有所长，在不同的拍摄场景下，需要灵活使用。中央平均测光保持了明亮与暗淡区域的平衡；中央部分测光使画面中央区域正确曝光；点测光使被曝光主体正确曝光。

三、更先进的自动曝光控制

事实上，无论哪种测光方式都很难兼顾整个画面的亮度。当光照条件是背光（逆光）或是强正面光时，由于场景中最亮和最暗区域具有强烈的对比度，如果仍然采用 上述的常用测光方法，虽然整体的图像亮度仍然是“中间灰度”，但是图像中重要的主体区域就肯定遭遇曝光不足或者曝光过度，所以必须采用更先进的自动曝光控制方法。

一种常用的方法是使用人工反光板进行光照补偿，这种方式常见于各种艺术照拍摄中。这种方式简单实用，但是对于个人摄影爱好者来说，由于需要携带额外的设备，就显得较为麻烦。除了人工光照补偿外，还可以采用手动设置曝光补偿的方式。

现在大部分数码摄像机都有曝光补偿设罝。曝光补偿是指在现有的曝光参数基础上再对其施加一定的补偿值，常见的是对曝光时间的补偿。在背光情况下，为突出正面主体可增加曝光时间，在正面强光下，可减少曝光时间。除了曝光参数的补偿外，还可以采取目标亮度补偿，即在“中间灰度”的基础上增加一个补偿值，达到相同的效果。

除了手动的曝光补偿外，另一种是自动的曝光补偿，目前使用的多是在自动曝光时能够主动识别主体的曝光控制算法。除了工业界已经商业化使用的一些算法外，学术界也有许多研究成果。例如，分区加权测光、基于亮度直方图的测光等。

自适应小波阈去噪-Adaptive Wavelet Thresholding for Image Denoising and Compression

发表于 2026-08-13 更新于 2026-09-21 分类于 图像处理

这篇论文《Adaptive Wavelet Thresholding for Image Denoising and Compression》提出了一种自适应的小波阈值去噪方法，称为 BayesShrink。它通过贝叶斯框架和广义高斯分布（GGD）建模小波系数的统计特性，实现了对每个子带的自适应阈值选择。下面我为你详细讲解其算法原理和实现步骤。

一、核心思想

图像去噪的目标是从带噪图像中恢复出原始图像：

[

g_{ij} = f_{ij} + \epsilon_{ij}, \quad \epsilon_{ij} \sim N(0, \sigma^2)

]

在正交小波变换域中，带噪小波系数为：

[

Y = X + V

]

其中 (X) 是原始信号的小波系数，(V) 是高斯噪声。阈值去噪的核心是：对小波系数进行非线性处理，保留大系数（代表信号），将小系数（代表噪声）置零。

BayesShrink 的核心贡献是：为每个子带推导出一个接近最优的闭式阈值。

二、BayesShrink 阈值的推导

1. 假设小波系数服从 GGD

广义高斯分布（GGD）定义为：

[

GG_{\sigma_X, \beta}(x) = C(\sigma_X, \beta) \exp\left( -[\alpha(\sigma_X, \beta)|x|]^\beta \right)

]

其中 (\sigma_X) 是标准差，(\beta) 是形状参数（自然图像中通常 (\beta \in [0.5, 1])）。

2. 贝叶斯风险最小化

定义软阈值函数：

[

\eta_T(y) = \text{sgn}(y) \cdot \max(|y| - T, 0)

]

贝叶斯风险为：

[

r(T) = E_X E_{Y|X} \left[ (\eta_T(Y) - X)^2 \right]

]

目标是找到最小化 (r(T)) 的 (T^*)。

3. 近似闭式解

通过数值计算发现，对于高斯（(\beta=2)）和拉普拉斯（(\beta=1)）先验，最优阈值可以近似为：

[

T_B = \frac{\sigma^2}{\sigma_X}

]

对于 (\beta \in [0.5, 1])，该阈值的风险与最优阈值相差不超过 5%。因此，BayesShrink 阈值为：

[

\hat{T}_B = \frac{\hat{\sigma}^2}{\hat{\sigma}_X}

]

三、参数估计（数据驱动）

为了实现自适应，需要从观测数据中估计 (\sigma) 和 (\sigma_X)。

1. 估计噪声标准差 (\sigma)

使用最细尺度子带 (HH_1) 的中位数估计：

[

\hat{\sigma} = \frac{\text{Median}(|Y_{ij}|)}{0.6745}, \quad Y_{ij} \in HH_1

]

2. 估计信号标准差 (\sigma_X)

由于 (Y = X + V)，且两者独立，有：

[

\sigma_Y^2 = \sigma_X^2 + \sigma^2

]

其中：

[

\hat{\sigma}Y^2 = \frac{1}{n^2} \sum{i,j} Y_{ij}^2

]

因此：

[

\hat{\sigma}_X = \sqrt{\max(\hat{\sigma}_Y^2 - \hat{\sigma}^2, 0)}

]

若 (\hat{\sigma}^2 \geq \hat{\sigma}_Y^2)，则 (\hat{\sigma}_X = 0)，此时阈值设为无穷大（所有系数置零）。

四、阈值处理流程

  1. 对带噪图像进行正交小波变换（如 Daubechies 小波，8 个消失矩，4 层分解）。

  2. 对每个细节子带（(HH_k, HL_k, LH_k)）：

    • 估计 (\hat{\sigma}) 和 (\hat{\sigma}_X)

    • 计算阈值 (\hat{T}_B = \hat{\sigma}^2 / \hat{\sigma}_X)

    • 应用软阈值函数处理系数

  3. 保留最低频子带 (LL_J) 不变。

  4. 执行逆小波变换，得到去噪图像。

五、与 SureShrink 的比较

  • SureShrink：基于 Stein 无偏风险估计（SURE），在某些子带可能选择过大的通用阈值（(\sigma\sqrt{2\log M})），导致过度平滑。

  • BayesShrink：阈值仅依赖 (\sigma) 和 (\sigma_X)，不依赖子带大小，更适应图像特性。

  • 实验表明，BayesShrink 的 MSE 通常比 SureShrink 低 1%~8%，并且接近 OracleShrink（已知原始图像的最优软阈值）的 5% 以内。

六、扩展：结合压缩的去噪（MDLQ）

论文还提出了一种基于最小描述长度（MDL）的量化方法，用于同时实现去噪和压缩：

  • 使用 BayesShrink 阈值作为量化器的“零区”

  • 对非零系数进行均匀量化，量化参数（(m, \Delta)）通过 MDLQ 准则选择

  • MDLQ 平衡了失真和编码长度：

    [

    \text{MDLQ} = \frac{1}{2\sigma^2 \log 2} \sum (Y_{ij} - \hat{X}^Q_{ij})^2 + L(\hat{X}^Q | m, \Delta)

    ]

  • 实验表明，压缩确实能去噪（尤其当 (\sigma) 较大时），但会引入量化噪声。

七、总结：BayesShrink 的优势

| 特点 | 说明 |

|——|——|

| 自适应 | 每个子带独立估计阈值 |

| 闭式解 | (T_B = \sigma^2 / \sigma_X)，计算高效 |

| 数据驱动 | 参数完全从观测图像估计 |

| 近最优 | 风险接近 OracleShrink |

| 鲁棒 | 对 GGD 形状参数不敏感（(\beta \in [0.5,1])） |
