自适应小波阈去噪-Adaptive Wavelet Thresholding for Image Denoising and Compression

发表于 2026-08-13 更新于 2026-09-22 分类于 图像处理

这篇论文《Adaptive Wavelet Thresholding for Image Denoising and Compression》提出了一种自适应的小波阈值去噪方法，称为 BayesShrink。它通过贝叶斯框架和广义高斯分布（GGD）建模小波系数的统计特性，实现了对每个子带的自适应阈值选择。下面我为你详细讲解其算法原理和实现步骤。

一、核心思想

图像去噪的目标是从带噪图像中恢复出原始图像：

[

g_{ij} = f_{ij} + \epsilon_{ij}, \quad \epsilon_{ij} \sim N(0, \sigma^2)

]

在正交小波变换域中，带噪小波系数为：

[

Y = X + V

]

其中 (X) 是原始信号的小波系数，(V) 是高斯噪声。阈值去噪的核心是：对小波系数进行非线性处理，保留大系数（代表信号），将小系数（代表噪声）置零。

BayesShrink 的核心贡献是：为每个子带推导出一个接近最优的闭式阈值。

二、BayesShrink 阈值的推导

1. 假设小波系数服从 GGD

广义高斯分布（GGD）定义为：

[

GG_{\sigma_X, \beta}(x) = C(\sigma_X, \beta) \exp\left( -[\alpha(\sigma_X, \beta)|x|]^\beta \right)

]

其中 (\sigma_X) 是标准差，(\beta) 是形状参数（自然图像中通常 (\beta \in [0.5, 1])）。

2. 贝叶斯风险最小化

定义软阈值函数：

[

\eta_T(y) = \text{sgn}(y) \cdot \max(|y| - T, 0)

]

贝叶斯风险为：

[

r(T) = E_X E_{Y|X} \left[ (\eta_T(Y) - X)^2 \right]

]

目标是找到最小化 (r(T)) 的 (T^*)。

3. 近似闭式解

通过数值计算发现，对于高斯（(\beta=2)）和拉普拉斯（(\beta=1)）先验，最优阈值可以近似为：

[

T_B = \frac{\sigma^2}{\sigma_X}

]

对于 (\beta \in [0.5, 1])，该阈值的风险与最优阈值相差不超过 5%。因此，BayesShrink 阈值为：

[

\hat{T}_B = \frac{\hat{\sigma}^2}{\hat{\sigma}_X}

]

三、参数估计（数据驱动）

为了实现自适应，需要从观测数据中估计 (\sigma) 和 (\sigma_X)。

1. 估计噪声标准差 (\sigma)

使用最细尺度子带 (HH_1) 的中位数估计：

[

\hat{\sigma} = \frac{\text{Median}(|Y_{ij}|)}{0.6745}, \quad Y_{ij} \in HH_1

]

2. 估计信号标准差 (\sigma_X)

由于 (Y = X + V)，且两者独立，有：

[

\sigma_Y^2 = \sigma_X^2 + \sigma^2

]

其中：

[

\hat{\sigma}Y^2 = \frac{1}{n^2} \sum{i,j} Y_{ij}^2

]

因此：

[

\hat{\sigma}_X = \sqrt{\max(\hat{\sigma}_Y^2 - \hat{\sigma}^2, 0)}

]

若 (\hat{\sigma}^2 \geq \hat{\sigma}_Y^2)，则 (\hat{\sigma}_X = 0)，此时阈值设为无穷大（所有系数置零）。

四、阈值处理流程

  1. 对带噪图像进行正交小波变换（如 Daubechies 小波，8 个消失矩，4 层分解）。

  2. 对每个细节子带（(HH_k, HL_k, LH_k)）：

    • 估计 (\hat{\sigma}) 和 (\hat{\sigma}_X)

    • 计算阈值 (\hat{T}_B = \hat{\sigma}^2 / \hat{\sigma}_X)

    • 应用软阈值函数处理系数

  3. 保留最低频子带 (LL_J) 不变。

  4. 执行逆小波变换，得到去噪图像。

五、与 SureShrink 的比较

  • SureShrink：基于 Stein 无偏风险估计（SURE），在某些子带可能选择过大的通用阈值（(\sigma\sqrt{2\log M})），导致过度平滑。

  • BayesShrink：阈值仅依赖 (\sigma) 和 (\sigma_X)，不依赖子带大小，更适应图像特性。

  • 实验表明，BayesShrink 的 MSE 通常比 SureShrink 低 1%~8%，并且接近 OracleShrink（已知原始图像的最优软阈值）的 5% 以内。

六、扩展：结合压缩的去噪（MDLQ）

论文还提出了一种基于最小描述长度（MDL）的量化方法，用于同时实现去噪和压缩：

  • 使用 BayesShrink 阈值作为量化器的“零区”

  • 对非零系数进行均匀量化，量化参数（(m, \Delta)）通过 MDLQ 准则选择

  • MDLQ 平衡了失真和编码长度：

    [

    \text{MDLQ} = \frac{1}{2\sigma^2 \log 2} \sum (Y_{ij} - \hat{X}^Q_{ij})^2 + L(\hat{X}^Q | m, \Delta)

    ]

  • 实验表明，压缩确实能去噪（尤其当 (\sigma) 较大时），但会引入量化噪声。

七、总结：BayesShrink 的优势

| 特点 | 说明 |

|——|——|

| 自适应 | 每个子带独立估计阈值 |

| 闭式解 | (T_B = \sigma^2 / \sigma_X)，计算高效 |

| 数据驱动 | 参数完全从观测图像估计 |

| 近最优 | 风险接近 OracleShrink |

| 鲁棒 | 对 GGD 形状参数不敏感（(\beta \in [0.5,1])） |
