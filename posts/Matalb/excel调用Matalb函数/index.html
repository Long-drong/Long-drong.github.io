方法 1：使用 MATLAB Compiler 生成 Excel 插件

  • 准备 MATLAB 函数：

    先确保你的 MATLAB 函数已经实现，并且能够正确运行。假设你的函数叫 myFunction.m，该函数接受输入并返回输出。

  • 使用 MATLAB Compiler：

    MATLAB Compiler 可以将你的 MATLAB 函数编译成一个动态链接库（DLL），从而可以在 Excel 中调用。

    你可以使用 deploytool 来创建一个 Excel 插件。

    • 打开 MATLAB 并输入：

    • 选择 Excel Add-in 项目类型。

    • 选择你的 MATLAB 函数（例如 myFunction.m）并配置参数。

    • 点击 Build 按钮生成插件。

  • 安装 Excel 插件：

    生成的插件文件（如 .xll 文件）可以直接安装到 Excel 中。安装完成后，你可以在 Excel 中像调用普通函数一样调用你的 MATLAB 函数。

  • 在 Excel 中调用：

    一旦插件安装完毕，你可以直接在 Excel 的单元格中使用 =myFunction() 这样的方式来调用你在 MATLAB 中编写的函数。

  • 参考地址：https://ww2.mathworks.cn/help/compiler/excel/create-an-excel-application-from-matlab-code.html
